# IR004：长按启停，运行时自动开启红外

2026-11-10。基线为用户已烧入且本机收到身份应答的冻结IR003；按本轮明确要求修改启动策略。此版用于配合电机与红外模块测试，保留完整IR003源码和产物供回滚，不作为整机量产程序。

## 使用行为

- 上电保持停止、红外关闭。任意一个机械键长按约3秒启动：电机立即获得运行输出，同时自动开启38kHz对射短脉冲。无需另发串口启用命令；未接红外也允许启动。
- 再次长按约3秒停止测试：取消运行请求、停止电机并关闭红外。一直按住只切换一次，须松手再长按；短按不累计，多键/换键不拼接长按，上电按住不启动。
- 每次开机先等待有效对射脉冲，未识别到之前允许电机测试，ARM=0。第一次识别到有效通光后ARM=1，随后遮挡或信号丢失立即禁止电机输出。
- 遮挡暂停期间REQ仍为1，红外继续检测；持续遮挡不恢复。重新连续通光10秒才恢复，期间再次遮挡从10秒重新计时。
- 等待期间长按关机或串口停止，取消恢复；之后即使通光也不自动启动。下一次长按开机重新识别光路。

“开关机”指测试运行状态，主控仍由12V供电，不是物理切断整板电源。独立串口发射诊断保留：只有已手动停止REQ0时才允许显式36/38/40kHz短时测试，最多10秒并恢复关闭；正常按键流程只在本轮运行请求有效时发射。

**测试限制**：ARM0不表示无人或安全，只表示本次开机尚未建立有效光路；此时原本已遮挡、未接模块或模块无信号都不会阻止电机，这是用户要求便于独立电机测试而明确修改的行为。ARM1之后断开接收信号也会暂停。当前接收模块型号/极性尚未实测确认，上一轮IR003在正对无遮挡时一直读低、无边沿；本轮并未宣称修好了光电链路。默认沿用低脉冲判据，须观察ARM1及真实遮挡响应，才能认定红外联动通过。

## 状态解释

例：`IR004 RUN KEYS=111 TX=4 RAW=0 RST=0051`，下一行`REQ=1 BEAM=2 ARM=0 WAIT=0000`。

- RUN/STOP为软件实际允许输出，不能替代物理转动观察；REQ是长按产生的用户请求。
- TX0关闭，TX1/2/3是有界36/38/40kHz测试，TX4/5是低/高脉冲连续对射模式。
- ARM0尚未建立光路，不阻止本轮电机测试；ARM1之后才按遮挡/失联暂停。
- BEAM0未判定，1符合当前对射窗口，2不符合；ARM0时BEAM2不意味着保护已经启动。
- WAIT为十六进制剩余10ms节拍，03E8=1000=10秒，0000无等待。手动关机清零，不留恢复任务。
- 默认38kHz、1ms/10ms载波包、载波约1/3占空比，接收窗口200us～5ms、2～8边沿、首次响应3ms内，均沿用IR003诊断配置，不能把软件假设当接收器规格。

## 用户复现

1. 准备：原12V供板，CH340三线如上且VCC不接。下载本页唯一IR004 HEX，查询任务应看到IR004 STOP、REQ0、TX0、ARM0；看到IR003说明仍是旧文件。下载/启动和物理动作分别验收。
2. 未接红外时，先松开三键，再任意一个键长按约3秒，应开始持续转动；日志应RUN/REQ1/TX4/ARM0。一直按住不会再次切换。松手后再长按约3秒，应停转且STOP/REQ0/TX0。
3. 停机断电后接回两块红外板，主板NEC→黄OUT、GND→黑、+5V→红VCC，发射T+/T-按原插座；两灯头正对无遮挡。上电仍停止；长按3秒启动应RUN。先查询确认ARM1，再遮挡；若一直ARM0，应先收集S/L/E和照片，继续查发射/输入配置，不把联动写成通过。
4. ARM1后遮挡，应STOP/REQ1/BEAM2、WAIT约03E8、TX仍4。保持遮挡超过10秒仍应停止；移开遮挡，连续通光不足10秒不恢复、满10秒恢复RUN。等待约9秒再次遮挡，须重计10秒。
5. 暂停等待期间长按3秒手动停止，应REQ0/TX0，之后通光超过10秒也不恢复。另测上电按住、短按、多键和第二/第三键，确认旧按键约束。

失败先保留“IR004查询/监视”生成的build/IR004-*.json、按键/遮挡时间和实际电机现象；不要连续重烧掩盖状态。回滚文件为`output/LB_IR003/LB_IR003.hex`，SHA256 `4bde5c9eef51f92eb879a9184fd21d533e387bb05582e5e3694de5270c9d1d51`；回滚会恢复IR003默认未知光路禁止电机的行为。
