# WIFI001 猫砂盆独立联网联调

2026-11-19，参照喂食器 WBR3 已实测链路，猫砂盆使用自己的涂鸦开发产品「wax宠物猫砂盆」，型号 002，PID `0m0kpxctdshaigt9`，Wi-Fi 与蓝牙配网。电机在实测中拔下，联调固件固定电机两路控制为低。经用户同意，按键启停、霍尔、红外和雷达控制在这份暂用镜像中停用。完整本地功能回退为冻结的 IR017。当前 C251 评估版代码上限 2KB，IR017 已占 2045 字节（链接器计许可占用），需要有足够容量的工具链再集成本地保护和联网。

## 板载通信

- WBR3 U6.16 TXD → Q3 → STC32G8K64 24/P5.0（UART3 RX），STC 25/P5.1（UART3 TX）→ Q2 → U6.15 RXD，U6.3 EN → 27/P3.6。EN 用高阻输入并沿用模组内部上拉。UART3 使用 Timer3，实板 9600 8N1。UART1 留给 CH340 状态与下载。
- 支持 `00` 心跳、`01` 产品信息、`02` MCU 协同模式、`03` 联网状态响应。显式 `04` 配网请求每次上电仅一次。本次手机首次添加使用模组已有待配网状态，未发送重置。
- 状态行记录 `B` 波特率选择（0=9600）、`N` 网络状态、`H/P/M` 握手计数、`S` 网络上报次数、`A` 人工配网发出/应答、`Q` 数据点查询、`D` 数据点下发帧数、`E/T` 串口错误计数、`O` 电机输出位。`Q` 只代表收到状态查询。`D` 只计帧，不启动动作，也不回报虚假的执行结果。

设计依据为原板生产布线 `build/cam-review/connectivity.json`，STC32G 手册 PDF 第 304、624–625、871、884 页，以及[涂鸦 WBR3 数据手册](https://developer.tuya.com/en/docs/iot/wbr3-module-datasheet?id=K9dujs2k5nriy)和[涂鸦 Wi-Fi MCU 基础协议](https://developer.tuya.com/en/docs/mcu-standard-protocol/MCUSDK-wifi-base?id=Kd2bxu84567gk)。

## 实测与复现

1. 电机拔下，保留主板 12V 及 CH340 原接法。断开 12V，运行 **猫砂盆 WIFI001: 下载 WBR3 联调版**，显示等待后接回。首次下载在第二个校频包前出现游离字节、擦除未开始。新增握手包头重同步后，以 COM9/38400 完成 16 块写入应答和退出，保持芯片硬件选项。固件返回 WIFI001 状态。
2. 运行 **猫砂盆 WIFI001: 监听配网状态**。`H/P/M` 非零证明串口握手通过，`N=0/1/6` 为待配网。只有确实需要清除旧网络时，使用单独的 **重新配网** 任务，观察应答和新的待配网上报。
3. 手机在「智能生活」用 2.4GHz Wi-Fi 添加猫砂盆。现场用户确认添加成功，串口记录 `N=00→03→04`，App 状态查询两次，电机控制 `O=00`。已验收手机发现及云端上线。清洁命令下发、状态上报和真实动作等待产品数据点联调。
