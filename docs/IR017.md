# IR017 雷达停机台架验证

从 IR016 增加雷达输入。雷达触发时撤销电机输出及本轮启动请求。雷达保持触发时长按也无法启动。信号解除后保持停止，下一轮仍由长按、霍尔和红外共同放行。

## 接口证据

主板丝印 `3V3 / GND / MW` 对应生产布线 CN6.1、CN6.2、CN6.3。CN6.3 经 Q8 到 MCU 第 7 脚 `P4.7`，R18 上拉至主板供电，R19 从 3.3V 给 Q8 偏置。CN6.4 在现有布线表上没有匹配的信号连接。板级位置取自贴片图第 2 页，走线取自 `build/cam-review/connectivity.json`，引脚及寄存器取自 STC32G 手册印刷第 264 页、第 1722 页。旧原理图第 7 页有同类电平转换，第 1 页的旧 MCU 脚位与实际生产板不同。

用户提供的雷达照片背面为 `MWB02-2211`，接头旁可辨 `V / G / O`。按用户确认的饮水机旧件比对，睿界 RA10U11C V1.0 文件第 2.1 表给出的典型频率为 10.525GHz、工作电压为 2.7～4.8V，输出高/低约 3.3/0V。原规格书使用五针连接器，本次照片为四针板，按供电规格匹配的旧件台架验证，精确型号对应未独立确认。采用 `V→3V3、G→GND、O→MW`，第 4 针留空。无元件的一面朝向检测区域。

## 实物验证步骤

1. 电机保持拔下，CH340 照 IR016 接线，模块先根据针序和规格完成适配。主板断开 12V，启动 VSCode **猫砂盆 IR017: 下载雷达停机验证**，显示等待后接回主板 12V。
2. 运行 **猫砂盆 IR017: 监听雷达与电机输出**，检查 `IRC S ... Q=0`，先记录无活动时的 `D`，再在模块前移动并等信号解除。重复确认有效电平。若读数不变，先核对采样日志、模块上电、端子映射与模块输出。
3. 实测确定极性后，在按键松开、主板待机时用 `tools/ir014.ps1 -Profile IR017 -Action status -RadarActive high`（触发为高）或 `-RadarActive low`（触发为低）选择。仅保存在本次上电的 RAM 中。
4. 固定磁铁使霍尔至少一路低，红外无遮挡。清空雷达检测区，长按约 3 秒，待 `IRC R Q=1` 后触发雷达。通过标准是同一条日志记录 `D` 进入触发态并回到 `IRC S Q=0`，解除后保持停止。若红外先挡住首次输出，先看 `B` 和霍尔，按独立电机台架入口隔离红外条件时须保持电机拔下。测试结束发停止命令。

IR017 镜像位于 `output/LB_IR017/LB_IR017.hex`，SHA-256 `023a6789c410ff2a62efac32f2664f7f286fb266dcab603fb83364ddb8de83ca`。回退入口为 **猫砂盆 IR016: 下载霍尔启动联动**。雷达小板的检测范围和运动机构的停止距离留待整机验证。

2026-11-19 现场采用 3.3V，验证高电平触发。独立台架日志记录 `IRC R Q=1 D=0 → IRC S Q=0 D=1 → IRC S Q=0 D=0`，测试后退出独立台架并确认待机。高电平触发仍是本次上电设置，重启后需要重新选择。正常红外模式与雷达同时接入的实板回归，及电机实际动作，均待验证。
