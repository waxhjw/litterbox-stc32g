# IR016 霍尔启动联动

从完整 IR015 继承长按 3 秒启停、三路红外联动、连续无遮挡 10 秒恢复、串口诊断和电机台架模式。新启动必须同时满足霍尔和已有启动条件。台架验收允许 `H0`、`H1`、`H2`，由 `H3` 拒绝启动。`H1` 表示 HLR1 低，`H2` 表示 HLR2 低，`H0` 表示两路低。

| 条件 | 预期 |
| --- | --- |
| 启动前两路霍尔高 | 长按后保持停止，`IRB S` 且 `Q=0` |
| 启动前任一路低 | 长按后接受启动请求，已有红外条件满足后进入 `IRB R` |
| 等待首次输出时两路恢复为高 | 取消待启动请求，恢复低电平后需松手并重新长按 |
| 已开始输出后两路恢复为高 | 本次运行可继续，遮挡时停止，连续无遮挡 10 秒后恢复 |
| 长按停止或掉电重启 | 回到停止，下一次启动重新检查霍尔 |

## 台架步骤

1. 电机接头保持拔下，CN2 接霍尔小板。CH340 的 TXD、RXD 交叉接主板串口，GND 共地，VCC 留空。红外探头对齐无遮挡，测试过程中保持无真实宠物和机械负载。
2. 断开主板 12V，运行 VSCode 的 **猫砂盆 IR016: 下载霍尔启动联动**，显示等待主控后接回主板 12V。下载完成后用 **猫砂盆 IR016: 监听霍尔、电机与红外状态** 确认 `IRB S` 和 `Q=0`。
3. 移远磁铁，用 **猫砂盆 IR016: 读取两路霍尔** 确认 `H3`。开启状态监听后长按任意一键 4 秒并松手。待机和 `Q=0` 应保持，期间出现运行请求或 `IRB R` 即为失败。
4. 固定磁铁，读取 `H0`、`H1` 或 `H2` 任一状态即可。开启状态监听，再长按任意一键 4 秒并松手。磁铁保持至实际输出，红外无遮挡后约 10 秒应出现 `IRB R`。失败时保存状态日志，优先比对 `K`、`Q`、`C`、`B` 和霍尔读数。
5. 长按 4 秒使状态回到 `IRB S`、`Q=0`。固件软件回归覆盖首次启动等待时丢失霍尔、已启动后离开磁铁及原红外暂停恢复。整机端点和机械动作需样机确认。

诊断基线及回退均采用 IR015 冻结镜像 `output/LB_IR015/LB_IR015.hex`，SHA-256 `aed050b52a998fffa968daf24b12346f89c1d941823cefe2471cac8bc1e4d5a7`。
